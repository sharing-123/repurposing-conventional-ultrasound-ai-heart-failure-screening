Error bars on the binary AUROC chart are 95% confidence intervals (DeLong method). The platform gap is largest for PLAX in binary classification. An exploratory unpaired DeLong test gave P < 0.001 for PLAX, P = 0.439 for A4C, and P = 0.864 for A2C. The test treats cine loops as independent and does not account for repeated loops from the same participant, so these P values should be read as descriptive. The multiclass chart shows macro balanced accuracy, because the shared predictions contain only the predicted class. Hover over any chart for the full metric breakdown per platform and view.

Methodology, in Brief

Full methodology is reported in the manuscript under TRIPOD+AI. Summary below.

Study design

  • Multicenter model-adaptation study, four tertiary hospitals in Indonesia.
  • LIFES echocardiographic AI model adapted to conventional convex ultrasound via transfer learning.
  • Two platforms compared: GE LOGIQ S7 (high-end) and Mindray DP-20 (low-end).
  • Views evaluated: PLAX, A4C, A2C PSAX acquired but excluded from the final analysis — see manuscript Methods.
  • Patient-level split: 70% training / 15% validation / 15% testing.

Data & Code Transparency

What is openly available here

  • All performance metrics reported in the manuscript (Tables 2–3), as raw CSV, including 95% confidence intervals (DeLong for binary AUROC, bootstrap for multiclass accuracy).
  • Baseline demographic and clinical characteristics (Table 1), independently recomputed from patient-level data with the statistical test named for every row.
  • The STARD-style participant flow counts (screened, excluded by reason, enrolled, and split into training/validation/testing).
  • The exploratory unpaired DeLong test comparing high-end versus low-end AUROC for every cardiac view.
  • The complete plotting pipeline (src/) that produces every chart on this page, directly from those CSVs, plus the analysis/ folder documenting the statistical methods (DeLong variance estimator, bootstrap routines) used to derive them from the underlying video-level predictions.
  • The rendered, interactive figures themselves (open any file in docs/assets/figures/).

What is intentionally not included

  • Patient-level imaging data and identifiable clinical records, withheld to protect participant privacy per the study's ethics approval. This includes the video-level AI prediction scores that the aggregate tables above were computed from.
  • The LIFES model weights and training pipeline, which remain the authors' ongoing research property.
