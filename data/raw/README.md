# Raw data (not included)

The private, patient-linked source file `Dataset_Acta_medica.xlsx` belongs
here when reproducing the analysis in [`analysis/`](../../analysis). It is
not committed to this repository to protect participant privacy, consistent
with the study's ethics approval. See [`analysis/README.md`](../../analysis/README.md)
for the expected sheet names and columns, and the manuscript's *Availability
of data and materials* statement for the full data-sharing policy.
